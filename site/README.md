# 缇娅的点歌台

## 更新歌单

1. 替换项目根目录中的四份 Word 文件（文件名保持不变）。
2. 保留 `歌单表格核对/核对资料/review_records.json`，其中记录了已确认的歌手匹配。运行 `tools/generate_data.py`，它会读取当前 Word，并沿用已核对条目的歌手，重新生成 `site/data.js`。新增歌曲需要另行核对歌手；二游分类不补歌手。
3. 提交并推送改动，GitHub Pages 会自动更新网站。

复制文案目前为：`我要点《歌名》`。如需修改，请编辑 `site/app.js` 中的 `copySong`。

学歌清单始终读取当前 Word，按 `【已学】` 和 `【排队中】` 分组，组内保留原文顺序。每条格式为 `点歌人—歌名`，前半部分不是歌手。歌曲内的短横线不会被拆分；两位粉丝点同一首歌时保留各自的排队记录。格式缺失会中止生成，避免将人名误当歌名。
